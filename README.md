# NCRRFS
## Non-convex regularized robust multimodal feature selection via self-representation learning for Alzheimer's disease diagnosis


### Data preprocessing
The complete data preprocessing workflow (in Chinese) can be found in the following document:  
[Data Processing](https://github.com/xiyu1007/ADNI_DATA_PROCESS/tree/master/V_2024_12_26)


### Code
Before running the code, please make sure the following packages are installed:

- **MATLAB**  R2024b  
- **LIBSVM** (required for classification). You can download and install LIBSVM from the official site:  
[https://www.csie.ntu.edu.tw/~cjlin/libsvm/index.html](https://www.csie.ntu.edu.tw/~cjlin/libsvm/index.html)

Please note that results may vary between parallel and sequential computations.  
However, with a fixed random seed and a fixed computation method, the selected features and results will always be consistent.
